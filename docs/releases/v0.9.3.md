# Folio 0.9.3

The audiobook player is rebuilt around chapters on both platforms, a player you close no longer
disappears or gets in the way, and Android can save its library again.

- **A player that fits on one screen.** The old player scrolled its chapter list underneath a
  controls panel that covered half the screen, so most chapters were hidden behind the controls.
  The player now opens as a full-height sheet coloured from the book's own cover, and nothing in it
  scrolls: cover, title, the current chapter, the timeline and the controls all fit. Swipe it down
  or tap the chevron to close it.
- **Chapters on their own timeline.** Tapping the current chapter, or the list button, opens every
  chapter on one timeline: finished chapters dimmed, the current one showing how far into it you
  are, and the time left in the book. Tap a chapter to jump to its start.
- **The timeline covers the current chapter.** Scrubbing now moves within the chapter you are in,
  the way the lock screen always has, so a long book still gives fine control. The time on the
  right is what is left of the chapter. On Android this replaces the whole-book slider, its snapping
  to chapter starts and the tick you felt when crossing one.
- **A mini player that stays out of the way.** Closing the player while a book is loaded leaves a
  small glass player above the tab bar, with the cover, the chapter and play/pause; tap it to reopen
  the player. On iPhone the old bar sat on top of the tab bar, so there was no way to change tabs
  while a book was loaded. Android had no mini player before.
- **Android can save books again.** 0.9.2 wrote a missing series position in a form Android's
  storage rejects, so importing a file or downloading a book failed for any title outside a series.
- **Telegram asks for its API ID and hash on each device.** Earlier packages carried the Telegram
  application identity inside the APK and IPA, where anyone holding the file could read it, and
  those files are published here. These packages carry none. After updating, open Server →
  Telegram and enter the api_id and api_hash from https://my.telegram.org/apps once on each device;
  they are stored encrypted on that device. Packages up to 0.9.2 still contain the old pair.

## Downloads and installation

- **Android:** `Folio-Android.apk`, version 0.9.3 (57), Android 8+. **Uninstall Folio first, this
  once.** This is the first release signed with Folio's own release key; 0.9.2 and earlier were
  signed with the debug key of whichever machine built them, and Android refuses an update signed
  with a different key. Uninstalling removes the books, progress and sign-ins kept on the phone:
  download books again from BookLore and sign in again. Later updates install over this one. It is
  also the first proper release build rather than a debug build, so the app's private data can no
  longer be read over a USB cable.
- **iPhone / iPad:** `Folio-iOS.ipa`, version 0.9.3 (16), iOS 17+. Unsigned ARM64 device package;
  sign and install with SideStore.

## Verification

- 86 iOS unit tests and 64 Android unit tests pass (one skipped on each), including new coverage
  for the cover colour, chapter lengths and white text staying readable on every backdrop.
- The iOS UI test for the mini player, and the Android player and playback-speed tests, drive the
  new player end to end: chapters sheet, jumping to a chapter, scrubbing within it, closing to the
  mini player, checking it sits above the tab bar, switching tabs and reopening the player. All pass.
  On iOS it failed against 0.9.2's layout, where the mini player covered the tab bar.
- The Telegram native-library tests pass on the Android emulator with this build's library.
- Seven other Android instrumented tests fail, and fail identically on 0.9.2's code with only the
  save fix applied, so they predate this release: availability badges, background playback, two
  KOReader flows, format buttons and two library screens.
- Packages: the APK is 0.9.3 (57), a release build that is not debuggable, arm64 TDLib included,
  signed with the Folio release key (certificate SHA-256 `cd51ae36…6bf2`). The IPA is 0.9.3 (16),
  unsigned, with TDLib. Neither contains `telegram-private.json`, and the publisher now refuses
  any package that does, as well as any APK signed with another key.
- The release APK was installed on an Android 15 emulator, where it opens and asks for a Telegram
  API ID and hash, as intended.
- **Not verified:** physical devices, SideStore installation, a Telegram sign-in, and chapters in
  LibriVox downloads on Android.
