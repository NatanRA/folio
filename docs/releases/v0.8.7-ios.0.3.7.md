# Folio — Android 0.8.7 / iOS 0.3.7

The Android bottom bar now matches the iOS one: a floating capsule over the page with a frosted-glass look, an accent pill that glides to the selected tab, and press-and-slide selection. iOS is unchanged and is re-published to keep the pair together.

- Android floating tab bar. The Material navigation bar is replaced by a capsule that floats above the page. Lists, the library grid and the Server screen pad their bottom so content scrolls clear of it. The bar still hides while a book or the audiobook player is open, and it sits under the blurred search layer like on iOS.
- Press-and-slide selection: press the bar and slide across it, and the pill follows your finger while tabs switch as it passes them. Tapping works as before.
- Glass look: real backdrop blur of the page on Android 12 and newer; a translucent tinted capsule on older versions.

## Downloads and installation

- **Android:** `Folio-Android.apk`, version 0.8.7 (52), Android 8+. Signed with the same certificate as the previous release; install over the existing app.
- **iPhone / iPad:** `Folio-iOS.ipa`, version 0.3.7 (11), iOS 17+. Same code as 0.3.6 apart from the version number. Unsigned ARM64 device package; sign and install with SideStore.

## Verification

- Android: a new instrumented test taps the bar, then slides from the first item to the third and back, checking the Downloads and Home screens appear; it failed on the old bar and passes now. The universal search, empty-state navigation, appearance and reader-return tests also passed on a Pixel emulator. The bar was checked visually on Home, Library and Server; the backdrop blur was not visually confirmed because the emulator library had no content behind the bar.
- iOS: no source changes since 0.3.6; the 0.3.6 verification applies.
- Release-publisher tests passed. Package versions, identities, archive integrity and Android signing-certificate continuity were checked.

Physical-device installation remains unverified.
