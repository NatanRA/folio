# Folio 0.9.2

Audiobooks held on your library server are now visible and downloadable, series come from the
catalogue instead of being guessed from titles, and listening positions follow you between devices.

- **Audiobooks from BookLore and BookOrbit.** Both servers label audiobooks correctly in their
  OPDS feeds, and Folio used to throw them away: every audio link fell through the e-book format
  map, after which iOS discarded the entry entirely and Android showed a card with no way to get
  it. A title can now carry both an e-book and an audiobook edition and stay one entry with two
  formats. Where a book offers a plain MP3 and a chaptered M4B, the chaptered one wins, so chapters
  survive the download. Only formats each platform can actually play are offered, which is why the
  lists differ: Opus is available on Android and not on iPhone, because AVFoundation cannot decode
  it.
- **Series come from the catalogue.** Folio inferred series by parsing title strings — "Title
  (Series #3)", "Title, Book 3", and a fallback that grouped books sharing a leading phrase. Both
  BookLore and BookOrbit state the series in the same feed, in different shapes, and Folio now
  reads both. Books with no catalogue behind them, such as anything imported locally, still fall
  back to reading the title, so nothing that worked before stops working.
- **Listening positions sync between devices.** Telegram audiobooks carry an identifier derived the
  same way on Android and iOS, so a position saved on one device is recognised on the other.
  Positions travel through the private annotation service in the background, with nothing to press.
  See [the service notes](../../services/annotations/README.md); it is separate from BookLore and
  from KOReader sync, and it must be hosted to be used.
- Book descriptions are read from `<content>` when `<summary>` is empty, so they will not go blank
  on Android for anyone moving from BookLore to BookOrbit.

## Downloads and installation

- **Android:** `Folio-Android.apk`, version 0.9.2 (56), Android 8+. Signed with the same
  certificate as the previous release; install over the existing app.
- **iPhone / iPad:** `Folio-iOS.ipa`, version 0.9.2 (15), iOS 17+. Unsigned ARM64 device package;
  sign and install with SideStore.

## Verification

- 79 iOS unit tests and 55 Android unit tests pass, including new coverage for audio editions,
  both series shapes and the position exchange. Two real defects were found by those tests while
  writing them: iOS discarded any catalogue entry that had no e-book edition, and a series link
  titled "#3" created a series literally named "#3".
- Both packages were confirmed to contain the Telegram application identity, so the API ID and
  hash fields stay absent.
- **Downloading an audiobook from a live server was not exercised**, nor was a position
  round-trip between two devices; both are verified by unit tests and compilation only. The
  simulator has no catalogue account and no second device.
- Release-publisher checks: package versions, identities and archive integrity verified, and the
  Android signing certificate checked against the 0.9.1 asset before publishing.

Physical-device installation remains unverified.
