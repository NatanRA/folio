# Folio — Android 0.8.3 / iOS 0.3.3

Android now reads QuickTime text chapter tracks in M4B audiobooks. Books whose chapters previously appeared missing can display their existing chapter names and timestamps without modifying or reimporting the audiobook. The reader supports local files and the range reads used by Telegram streaming.

- Chapter extraction follows the referenced text track, supports 32-bit and 64-bit chunk offsets, and applies track edit timing. Metadata reads and sample counts are bounded, and audio payloads are skipped.
- Existing MP3 ID3 CHAP and MP4 Nero `chpl` support remains available.
- iOS already supports this chapter format through AVFoundation. Version 0.3.3 is a fresh paired build with no chapter-reader behavior change.
- README download buttons automatically follow this release. Current Folio filenames and legacy Media Portal aliases are included with SHA-256 checksums.

## Downloads and installation

- **Android:** `Folio-Android.apk`, version 0.8.3 (48), Android 8+. Signed with the same certificate as the previous release; install over the existing app.
- **iPhone / iPad:** `Folio-iOS.ipa`, version 0.3.3 (7), iOS 17+. Unsigned ARM64 device package; sign and install with SideStore.
