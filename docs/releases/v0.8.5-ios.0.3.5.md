# Folio — Android 0.8.5 / iOS 0.3.5

The library can be sorted, and iOS gains the same offline dictionary as Android. A sort icon beside search on the Library and Downloads tabs opens a menu with Title, Author, Series and Date added; the choice is remembered. Series are recognised from the titles themselves, so numbered sets such as the Harry Potter books fall into order without any extra metadata.

- Library sorting on both platforms. Title and Author ignore a leading "The", "A" or "An"; unknown authors sort last; Date added is newest first. Every book now records when it was added, and books saved before this take the date their file arrived on the device.
- Series detection from titles: explicit markers such as "(Discworld #3)", "Discworld #3: Equal Rites" or "…, Book 3" give the number, and books by the same author whose titles share a leading phrase are grouped, so "Harry Potter and the Chamber of Secrets, Book 2" sorts after "…Philosopher's Stone, Book 1". Standalone books follow the series alphabetically.
- iOS bundles Princeton WordNet 3.0 with the same lookup rules as Android. Define sits in the reader's selection menu and opens a sheet with an editable lookup, grouped senses, examples and the WordNet credit. Saved words gain a Define button.
- iOS library grid rows align to the top and covers rest on a shared bottom edge, so a tile with a progress bar no longer pushes its neighbour down.
- On the last page of an iOS book, Mark as finished sits above the page controls instead of covering them.

## Downloads and installation

- **Android:** `Folio-Android.apk`, version 0.8.5 (50), Android 8+. Signed with the same certificate as the previous release; install over the existing app.
- **iPhone / iPad:** `Folio-iOS.ipa`, version 0.3.5 (9), iOS 17+. Unsigned ARM64 device package; sign and install with SideStore. The package grows by about 10 MB for the dictionary, which expands to about 23 MB of app storage on first lookup.
