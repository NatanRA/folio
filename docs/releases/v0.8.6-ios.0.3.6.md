# Folio — Android 0.8.6 / iOS 0.3.6

A small iOS fix: the Appearance sheet now follows the Light, Dark or System setting the moment it is changed, instead of keeping the scheme it opened with. Android is unchanged and is re-published to keep the pair together.

- iOS Appearance sheet: a presented sheet keeps the colour scheme it was shown with, so switching Light or Dark from inside it updated the app behind it but not the sheet itself. The sheet now applies the setting it changes.

## Downloads and installation

- **Android:** `Folio-Android.apk`, version 0.8.6 (51), Android 8+. Same code as 0.8.5 apart from the version number. Signed with the same certificate as the previous release; install over the existing app.
- **iPhone / iPad:** `Folio-iOS.ipa`, version 0.3.6 (10), iOS 17+. Unsigned ARM64 device package; sign and install with SideStore.

## Verification

- iOS: a new UI test opens the Appearance sheet, switches to Dark then Light, and samples the sheet background each time; it failed before the fix and passes after. The existing appearance navigation test also passed on an iPhone 17 Pro simulator.
- Android: no source changes since 0.8.5; the 0.8.5 verification applies.
- Release-publisher tests passed. Package versions, identities, archive integrity and Android signing-certificate continuity were checked.

Physical-device installation remains unverified.
