# Folio — Android 0.8.8 / iOS 0.3.8

Two fixes. The iPhone Appearance sheet now changes theme the moment you choose one instead of waiting until it is closed and reopened, and the Android server form no longer arrives with a personal server address and username already filled in.

- iOS appearance: choosing Light, Dark or System repaints the Appearance sheet immediately, along with the page behind it. The sheet previously kept the theme it was presented with, so the setting only appeared to take effect after dismissing and reopening it. A sheet is presented outside the root view's hierarchy, so the root's `preferredColorScheme` never reached it and a copy inside the sheet was only read as the sheet appeared. The setting is now applied to the window and everything presented over it from a single place, instead of by two mechanisms that could disagree.
- Android server setup: the BookLore address and OPDS username fields start empty with an `https://your-server` hint, rather than pre-filled with the developer's own server and account. Connect library now stays disabled until an address, a username and a password are all present; it previously relied on the address and username being pre-filled.

## Downloads and installation

- **Android:** `Folio-Android.apk`, version 0.8.8 (53), Android 8+. Signed with the same certificate as the previous release; install over the existing app.
- **iPhone / iPad:** `Folio-iOS.ipa`, version 0.3.8 (12), iOS 17+. Unsigned ARM64 device package; sign and install with SideStore.

## Verification

- iOS: checked on an iPhone 17 Pro simulator running iOS 26.5 with the Appearance sheet open throughout. Dark to Light, Light to Dark, and System following the device while it was switched to dark all repainted the sheet, the sheet's own background and the page behind it without dismissing. The existing appearance UI test passes, along with 26 unit tests (1 skipped).
- Android: application and instrumented-test sources compile. The empty-state server test now types an address and username, which it previously inherited from the removed pre-filled values. Instrumented tests were not executed for this release; no emulator or device was attached.
- Release-publisher checks: package versions, identities and archive integrity verified by the publish helper. Android signing-certificate continuity confirmed against the 0.8.7 asset before publishing.

Physical-device installation remains unverified.
