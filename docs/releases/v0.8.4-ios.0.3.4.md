# Folio — Android 0.8.4 / iOS 0.3.4

Search moves out of the pinned strip and into the toolbar. Tapping the magnifier opens a search layer over the current page: the page blurs behind it, the field takes focus, and results sit directly in the blur. Tapping the blurred area, the X, or a tab closes it. The audiobook player is aligned across both platforms, and Telegram streaming on iOS recovers after an app update.

- Toolbar search icon on every tab, with a blurred, translucent search layer instead of a permanent search field above the page. Autocorrect is off in the field.
- On iOS, opening a book from search closes the layer and pushes the book on the current tab, so the tab bar stays visible. The Server tab hands off to Home.
- On iOS, the mini player no longer shows under the full audiobook screen, which previously stacked a second play button and a duplicated title.
- The Android audiobook player matches the iOS layout: an Audiobook header with a back arrow, larger shadowed cover, centred title and chapter name, position and duration at each end of the slider, sleep timer beside speed, and 15/30-second skip icons around a capsule play button.
- iOS Telegram streaming: TDLib stores absolute file paths, and iOS moves the app's data container on every update, so a partially cached stream failed with "The requested URL was not found on this server" until the cache aged out. The range reader now detects the stale file and re-downloads.

## Downloads and installation

- **Android:** `Folio-Android.apk`, version 0.8.4 (49), Android 8+. Signed with the same certificate as the previous release; install over the existing app. The blur behind search needs Android 12 or newer; older versions show a translucent layer without blur.
- **iPhone / iPad:** `Folio-iOS.ipa`, version 0.3.4 (8), iOS 17+. Unsigned ARM64 device package; sign and install with SideStore. The transparent search layer needs iOS 18 or newer; iOS 17 shows it on a solid background.
