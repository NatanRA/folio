# Folio — Android 0.8.2 / iOS 0.3.2

The app is now Folio, with the approved rounded stack of books as its logo. The cover and spine joins are smooth at both launcher and toolbar sizes. Existing app identifiers, libraries, settings and saved progress are preserved.

- In-app branding follows your selected accent colour. Android 13+ also supports wallpaper-themed launcher icons.
- The same approved SVG generates the native Android vectors, iOS template image and iOS app icon.
- Both platforms include the Telegram streaming, unified search, PDF/CBZ OPDS support and Telegram chat-recovery improvements added since the previous paired release.
- README download buttons always follow the latest paired release. Every release uploads `Folio-Android.apk` and `Folio-iOS.ipa`, verifies the draft assets, and includes checksums. Older Media Portal download URLs remain supported.

## Downloads and installation

- **Android:** `Folio-Android.apk`, version 0.8.2 (47), Android 8+. Signed with the same certificate as the previous release; install over the existing app.
- **iPhone / iPad:** `Folio-iOS.ipa`, version 0.3.2 (6), iOS 17+. This is an unsigned ARM64 device package; sign and install with SideStore.
- `SHA256SUMS.txt` covers both packages and their legacy filename aliases.

## Verification

- Android build, lint, eight unit tests and the native appearance/persistence test passed.
- iOS device build, ten unit tests, universal-search UI test and navigation/appearance UI test passed. One opt-in public-network test was skipped.
