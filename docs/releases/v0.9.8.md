# Folio 0.9.8

Listening positions move between your phones reliably. Sync worked in 0.9.2 to 0.9.7, but several
cases lost a position or pulled a phone back to an older one. This release fixes them. Nothing on
screen changes.

- **A phone set up fresh catches up.** Positions saved before sync existed had no "last changed"
  time, so they were never sent. On first launch each one is now dated once, from when its book was
  last opened, and sent.
- **Opening a book no longer rewinds your other phone.** Going back to a saved place, or trimming it
  to an audio length this phone measures slightly differently, used to count as a new save. That
  could beat a newer position from the other phone and send it back. Now only a move you make
  counts.
- **A position that arrives while a book is loading is kept.** Before, the book's old position was
  saved straight back over it. It now stays marked until the player has moved there.
- **A paused book takes a position from the other phone.** Before, any book loaded in the player
  was protected from incoming positions. Now only a book you're listening to is, and only until
  its latest position is saved.
- **A clock put back can't make a phone lose to itself.** Save times only ever move forwards.
- **iPhone: switching audiobooks keeps the one you left where it was.** Opening the next book could
  save the previous one at the wrong place, for example hours in recorded as minutes.
- **Android:** positions from the other phone are applied once the Telegram library has finished
  loading, not part-way through. Android now saves on a background thread, so a save made just
  before a position arrived is dropped rather than written over it.

Only Telegram audiobooks sync, because only they have the same ID on both platforms. Sync needs the
notes server (`services/annotations`) running and set up in the app on both phones. The server
itself is unchanged.

## Downloads and installation

- **Android:** `Folio-Android.apk`, version 0.9.8 (62), Android 8+. Signed with the Folio release
  key; install over the existing app.
- **iPhone / iPad:** `Folio-iOS.ipa`, version 0.9.8 (21), iOS 17+. Unsigned ARM64 device package;
  sign and install with SideStore.

## Verification

- **Android:** builds clean and 124 unit tests pass, including the position sync tests: later
  write wins, equal-time ties take the further position, first-launch dating, monotonic stamps and
  pulled positions.
- **iOS:** 115 unit tests pass (one skipped, the live-network catalogue download), including 27
  position sync tests.
- **Not verified:**
  - Sync between two real phones through a running notes server.
  - SideStore installation.
